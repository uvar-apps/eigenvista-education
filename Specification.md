EigenVista (GitHub: https://github.com/uvar-apps/eigenvista, Website: https://uvar-apps.github.io/eigenvista/, local project: ~/projects/eigenvista) is a molecular visualization tool for quantum chemistry and molecular compounds.

Review the project in details both on github and locally, also look at all the material on the website, then start creating educational content in this repo which maps https://github.com/uvar-apps/eigenvista-education.git.

All educational content must be accessible through a top level website served through github pages, check the workflow used by eigenvists to expose folders in the main repo as websites.

## Phase 1 - General Tutorials

Four tutorials with a tour of all the features:

1. Tutorial 1: target quantum chemistry researchers showing how to use all the relevant features split into two versions:
   1. Tutorial 1.1: access through GUI for users using the Graphical User Interface
   2. Tutorial 1.2: access through the AI-connector from prompts sent through an agent
2. Tutorial 2: target chemistry researchers in all the other spaces, including  the ones studying proteins and biomolecules.
   1. Tutorial 2.1: access through GUI for users using the Graphical User Interface
   2. Tutorial 2.2: access through the AI-connector from prompts sent through an agent

## Phase 2 - Workflows

Intentify three or four workflows used by quantum chemistry researchers and three or four workflows used by researchers studying proteins, materials, catalysts etc. and write relevant tutorials which each tutorial split into two: one for access through the GUI and one for access through the AI connector and coding agents.
